# 作品名称

增量型旋转编码器调试切换小灯颜色与PWM呼吸进度展示

编号：77




## 1. 功能概述

1.旋转编码器调节 LED 呼吸灯亮度

2. OLED屏显示亮度范围

3. 按下编码器按键切换灯光工作模式

 4. 限制亮度范围，避免亮度溢出





## 2. 硬件清单


| 名称 | 型号 | 数量 | 用途 |

|------|------|------|------|

| STM32 开发板 | STM32F103C8T6 | 1 | 主控 |

| 执行器示例 | SG90 | 1 | 动作输出（按实际替换） |

| 增量型旋转编码器 |         EC11            | 1 |   调节亮度、呼吸速度，自带按压按键 |

|         LED灯           |板载RGB单色LED | 3 |                      呼吸灯光输出                |
|      OLED显示屏     | 0.96寸I2C OLED   | 1 |                      实时显示参数                |



## 3. 接线表

| 信号 | STM32 引脚 | 外设引脚 | 备注 |

|------|-----------|----------|------|

| PWM1 | PA0 / TIM2_CH1 | 执行器信号线 | 示例，按实际改 |

| RCC_OSC_IN | PD0 | 8MHz 晶振一脚（+20pF 到 GND） | HSE 外部晶振，与 PD1 成对 |
| RCC_OSC_OUT | PD1 | 8MHz 晶振另一脚（+20pF 到 GND） | 同上 |
| TIM3_CH1 | PA6 | 电机/执行器驱动 PWM 输入 | TIM3 定时器 |
| TIM3_CH2 | PA7 | 电机/执行器驱动 PWM 输入 | TIM3 定时器 |
| TIM3_CH3 | PB0 | 电机/执行器驱动 PWM 输入 | TIM3 定时器 |
| Key | PB15 | 按键另一端接 GND | 内部上拉，按下为低电平 |
| TI1FP1 | PA8/TIM1_CH1 | 电机驱动 PWM 输入 | TIM1 高级定时器 |
| TI1FP2 | PA9/TIM1_CH2 | 电机驱动 PWM 输入 | TIM1 高级定时器 |
| SYS_JTMS-SWDIO | PA13 | ST-Link SWDIO | 调试/下载口 |
| SYS_JTCLK-SWCLK | PA14 | ST-Link SWCLK | 调试/下载口 |
| I2C1_SCL | PB6 | 传感器/OLED 的 SCL |  |
| I2C1_SDA | PB7 | 传感器/OLED 的 SDA |  |
